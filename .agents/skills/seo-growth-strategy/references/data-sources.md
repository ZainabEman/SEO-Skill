# Data sources

Use the live connected OpenSEO tool schema. The capability registry in config describes observed metadata and does not grant any spending authority. Match the exact site, market, date window, device and authorized project. Distinguish third-party estimates from connected Search Console clicks and impressions and GA4 sessions or approved key events. Report unconnected properties as unavailable.

Use provider data where available for rankings, traffic estimates, gaps, keyword volume, difficulty, CPC, SERPs, links, and location-specific reports. Distinguish Google Business Profile from general organic visibility and apply it only when the business offers a location or service area that makes it relevant. Use first-party public service, proof and contact pages for comparison. Label public web search as candidate discovery with its query and date, and do not infer Google ranking from generic web results.

OpenSEO methods informing the workflow include project context reuse, selective audit priorities, small keyword seed sets, mapping by page intent, evidence-based competitor selection, location-specific map research, and evaluating whether proposed link assets are genuinely citeable. Output is DOCX and XLSX as requested. Do not write reports or modify projects in OpenSEO during a standard run.
