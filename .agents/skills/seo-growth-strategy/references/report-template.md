# Report contract

Write sources.json as an object keyed by source ID. Values are sanitized source records with precise field-level evidence. Report JSON metadata keys are client, website, market, date, and language. Add `sections` (array of objects with title and claims) and `tables` (object keyed by SHEETS in validate_report.py). Each claim has id, tag, text, evidence (objects with source and pointer) and optional findings (IDs of supports). Each table has columns and rows, and may have a localized title. Sources columns in order are ID, URL, Datum, Markt, Anbieter, Grenzen. Use Beleg for single-source workbook references. Plain numerical claims require directly referenced scalar evidence. Express qualitative proposals without quantitative promises. For native numeric workbook cells add table.metric_evidence keyed by zero-based row index as a string, then by column name. Its value has source, pointer, tag (M, F or E) and unit. Each source field must resolve to the actual numeric value.

Use 23 sections in order. Executive Summary, Business and Website Overview, Current Website Audit, Technical SEO Audit, Organic Search Visibility, Competitor Discovery and Selection, Detailed Competitor Analysis, Competitor Comparison, Keyword Research, Keyword Gap Analysis, Backlink and Authority Analysis, Content Gap Analysis, Website Positioning Analysis, Conversion and Landing Page Analysis, SEO Strategy, Content Strategy, Website Growth Strategy, Recommended Website Improvements, Prioritized Action Plan, Short-/Medium-/Long-Term Roadmap, KPIs and Measurement Framework, Scope, Research Sources, Methodology, and Limitations (all three source topics in one section). Mark unavailable sections explicitly. Review generated links and source field pointers alongside layout.
