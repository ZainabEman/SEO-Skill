# Run an SEO growth strategy

Your workspace administrator grants access to the repository and the shared Cloud environment. Use your own account. Open the environment in Codex and select **SEO Growth Strategy** from the supported skill selector. In ChatGPT type `@` to look for the skill where the selector supports it. In Codex CLI and the IDE use `$seo-growth-strategy` or `/skills` as documented.

Example request after selecting the skill.

```text
https://example.com
Market DE/de, Lite, report in German.
```

You can add competitor URLs, Full, a different report language, or a PDF. If you omit competitors, the skill looks for candidates and validates service overlap.

Public-page research and explicitly zero-credit project reads are included. Other OpenSEO research requires separate approval for the exact planned calls and exposure, and is gated until the production transport is ready. Missing ranking, traffic or link metrics are marked unavailable. The run returns editable Word and Excel files using the delivery route configured by your workspace.

Repository maintainers update the skill. The environment owner publishes reviewed versions and manages access. Fresh published-environment and teammate invocation checks are pending.
