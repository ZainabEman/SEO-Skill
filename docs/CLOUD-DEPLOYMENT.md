# Cloud deployment

1. Review the implementation pull request in [SEO Skill](https://github.com/ZainabEman/SEO-Skill). Use its branch for evaluation. After review, deploy the approved branch. The public repository holds reusable source and synthetic fixtures.
2. In Codex Cloud environment settings, connect the repository and select Python 3.11 or newer. Set the custom setup script to `./setup.sh`. In a managed environment setup flow, save the draft and check setup before publishing.
3. Allow the approved public research targets and their required hostnames for agent-phase network access. Enable OpenSEO for the authorized workspace identity. To support PDF, provision LibreOffice.
4. Publish the environment for the authorized workspace group. Start a fresh task on the approved branch, select SEO Growth Strategy and run a zero-credit audit. Confirm artifact download using an approved private route.
5. Repeat the skill and delivery check from a second authorized account. Public repository access by itself does not grant access to the shared environment or OpenSEO account.

Use repository-scoped discovery first. If cross-project distribution is necessary, package the same skill in an approved private workspace plugin after administrator review.
