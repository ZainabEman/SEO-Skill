# Team access

Use individual authorized accounts. The repository owner grants read access to teammates and branch permissions to maintainers. The workspace owner shares the published environment with the intended members where the workspace supports it. The OpenSEO owner separately grants access to appropriate project data and verifies the identity model for teammates.

Cross-user access must be tested with another account. Verify environment selection, repository visibility, skill selection, zero-credit project resolution, and artifact download with a targeted public pilot.
